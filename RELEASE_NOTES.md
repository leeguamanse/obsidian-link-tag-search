Initial release of Link Tag Search.

- Edit native note tags and separate tags for each internal or web link.
- Search notes and individual links together using words, phrases, or tags.
- Keep tags in Markdown files so they remain readable without the plugin.
- Protect note content from stale edits and update search results as files change.

Requires Obsidian 1.13.7 or later. The interface is currently in Korean.
Tested on Windows; mobile and large vaults have not yet been tested.

For manual installation, download the three assets (`main.js`, `manifest.json`,
and `styles.css`) into your vault's `.obsidian/plugins/link-tag-search/` folder,
then enable Link Tag Search in Community plugins.
