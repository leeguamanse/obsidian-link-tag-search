실제 앱 검증 (2026-10-05):
- 사용자의 보관함 신뢰 승인 후 플러그인과 전용 검색창 정상 로드.
- #예산 검색: 관련 노트 2개와 해당 태그의 링크 1개 표시.
- 검색 결과에서 특정 링크에 #실제검증 추가 후 Markdown 저장 확인.
  같은 대상을 가리키는 다른 링크의 태그는 유지됨.
- #실제검증 + 링크 필터: 수정한 링크 1개만 표시.
- 링크 결과 제목 클릭: 원본 노트의 해당 줄로 이동 및 강조 표시.
- 명령어 팔레트에서 노트 태그 편집, #노트검증 추가 저장 및 검색 확인.
  저장 전후 본문을 비교하여 기존 본문과 링크 태그 보존 확인.
- Obsidian 종료 후 재실행: 플러그인 자동 로드, 노트 태그 유지,
  저장한 링크 태그의 검색 결과 유지 확인.
- 기본 검색의 tag:#실제검증: 태그가 있는 원본 노트 1개 표시 확인.

검증 범위: 테스트 보관함의 샘플 노트 3개.
대규모 실사용 보관함 및 모바일 기기에서는 아직 검증하지 않음.
