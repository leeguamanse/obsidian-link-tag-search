Link Tag Search 0.1.0
노트와 개별 링크의 태그 통합 검색

사용법
------
1. 명령어 팔레트(Ctrl+P)에서 다음 명령을 실행합니다.
   Link Tag Search: 태그 통합 검색 열기
   Link Tag Search: 현재 노트 태그 편집
   Link Tag Search: 현재 노트의 링크 태그 편집
2. 왼쪽 리본의 태그 아이콘으로도 검색창을 열 수 있습니다.
3. 노트에서 링크 안에 커서를 놓고 링크 태그 편집 명령을 실행합니다.
   커서가 놓인 링크를 우선 선택합니다. 커서가 링크 밖에 있으면 현재 줄에
   링크가 하나일 때 그 링크를 선택하고, 그 외에는 노트의 링크 목록을 엽니다.
   편집기 우클릭 메뉴와 검색 결과의 태그 편집 버튼도 지원합니다.

태그 저장 방식
--------------
노트 태그: 옵시디언의 기존 tags 속성을 사용합니다.
본문의 #태그도 검색에 포함됩니다. 본문 태그는 본문에서 수정하세요.
태그 편집은 다른 노트 속성이나 본문을 제거하지 않습니다.

개별 링크 태그: 같은 줄에서 링크 바로 뒤에 {#태그 #다른태그}를 붙입니다.
  [[회의록]] {#예산 #검토}
  [도움말](https://help.obsidian.md/) {#자료}
  https://example.com {#읽을거리}

같은 링크가 여러 번 나와도 각 위치에 다른 태그를 붙일 수 있습니다.
  [[회의록|예산 검토]] {#예산} 와 [[회의록|다음 회의]] {#일정}
위에서 #예산 검색은 첫 번째 링크만 링크 결과로 표시합니다.
링크의 태그가 연결된 대상 노트의 tags 속성을 바꾸지는 않습니다.

검색
----
전용 '태그 통합 검색' 창에서 제목, 본문, 링크 주소, 태그를 함께 찾습니다.
  예산          : '예산'이 포함된 제목/본문/링크/태그
  #예산         : '예산' 태그 또는 '예산/...' 하위 태그
  tag:#예산     : 위와 같은 태그 검색
  예산 검토     : 두 검색어를 모두 포함하는 결과
  "회의 기록"   : 공백을 포함한 구문

전체/노트/링크 필터를 제공합니다. 제목을 누르면 링크가 들어 있는
원본 노트의 위치로 이동합니다. '연결된 노트 열기' 또는 '웹 링크 열기'는
링크의 목적지를 엽니다. 태그를 누르면 해당 태그로 다시 검색합니다.

옵시디언 기본 검색은 바꾸지 않습니다. 저장된 #태그가 보통의 Markdown
태그이므로 기본 검색의 tag:#예산으로 태그가 들어 있는 노트를 찾을 수
있습니다. 개별 링크를 별도 결과로 보여주는 것은 전용 검색창 기능입니다.
기본 빠른 전환기(Ctrl+O), [[링크]] 자동 완성의 동작은 변경하지 않습니다.
공식 참고: https://obsidian.md/help/tags
공식 참고: https://obsidian.md/help/plugins/search

설치
----
Obsidian 1.13.7 이상이 필요합니다.
1. 원하는 보관함의 .obsidian/plugins/link-tag-search 폴더를 만듭니다.
2. 함께 제공된 link-tag-search 폴더의 main.js, manifest.json, styles.css
   세 파일을 그 안에 복사합니다.
3. 옵시디언을 다시 열고 설정 > 커뮤니티 플러그인에서
   Link Tag Search를 활성화합니다. 실행 동의창은 직접 확인해 주세요.

이미 플러그인이 설치되어 있다면 세 파일을 교체하기 전에 백업하세요.
작동 중인 실제 보관함에는 이 개발 작업에서 자동 설치하지 않았습니다.
시험용 dev-vault에는 시험 노트와 플러그인만 들어 있습니다.

개발 및 검증
------------
외부 npm 패키지 없이 Node.js만으로 빌드합니다.
배포 ZIP을 압축 해제한 뒤 source 폴더에서 다음 명령을 실행합니다.
  node build.cjs
  node --test test/core.test.js test/plugin.test.js
결과물은 dist 폴더에 만들어집니다.

한글/이모지 태그, 반복 링크, 같은 줄의 서로 다른 링크, URL 괄호와 조각,
코드/주석 제외, 노트 이름 변경 및 삭제, 비동기 검색 목록 갱신,
다른 속성 보존, 편집 중 내용 변경 시 저장 거부 등 자동 테스트 33개 통과.
실제 앱에서의 검증 상태는 VERIFICATION.txt를 참고하세요.

지원 범위
---------
내부 [[링크]], [제목](주소), <https://주소>, 본문에 붙여 넣은
http/https 주소를 지원합니다. 이미지와 임베드, 코드, 주석은 제외합니다.
참조형 링크([제목][참조]), 줄을 넘기는 링크, 복잡하게 중첩된 Markdown
목록 안의 코드 구문은 첫 버전에서 완전하게 지원하지 않습니다.
검색은 기본 검색의 OR/정규식/속성 연산자 전체 문법을 구현하지 않습니다.
모바일 실기기에서는 아직 검증하지 않았습니다.

플러그인 자체는 데이터를 외부로 전송하지 않습니다. 검색 목록은 메모리에
만들며, 사용자가 저장을 누른 태그만 해당 Markdown 노트에 기록합니다.
편집 중 노트가 바뀌면 이전 내용으로 덮어쓰지 않고 다시 열도록 안내합니다.
플러그인을 꺼도 저장된 노트 태그와 링크 옆 태그 문자는 그대로 남습니다.
